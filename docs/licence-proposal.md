# Licence proposal (needs the owner's decision)

**Proposal: Apache License 2.0.**

## Why a decision is needed

The contest rules ask for an open-source application published on GitHub or GitLab. Your previous project used PolyForm Noncommercial 1.0.0. That licence is source-available, not OSI-approved open source, so it would likely not meet this requirement.

## What open source means for resale

No OSI-approved licence prevents commercial use or resale, and that includes Apache-2.0, MIT and GPL. Anyone could use, modify, redistribute or sell CareBridge AI, or a product built on it.

| Licence | Commercial use and resale | Patent grant | Copyleft |
|---|---|---|---|
| Apache-2.0 (proposed) | Allowed | Yes, explicit | No |
| MIT | Allowed | No explicit grant | No |
| GPL-3.0 / AGPL-3.0 | Allowed, but derivatives must stay open | Yes | Yes; AGPL also covers network use |
| PolyForm Noncommercial | Not allowed | — | Not OSI open source |

Apache-2.0 is proposed for its explicit patent grant and attribution and NOTICE requirements. If you'd rather make commercial reuse less attractive while staying open source, AGPL-3.0 is the strongest option: anyone who modifies it and runs it as a service must publish their changes. It still does not forbid selling.
