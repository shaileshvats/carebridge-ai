# Changelog

## 1.0.0 (2026-11-04)
- First release for the InterSystems Programming Contest "AI Agents in Interoperability Workflows".
- Interoperability production with HIS and LIS MLLP services, a result router, an AI Hub exception-investigator agent, a deterministic policy gate, an EMR receiver, quarantine, reject ACKs, Workflow Engine review and a retry scheduler using a custom inbound adapter.
- Replay mode (no API key) and live mode (any AI Hub provider, including local OpenAI-compatible servers).
- Dashboard: overview, message explorer with an end-to-end trace, manual review, agent activity and demo scenarios.
- Unit, integration and adversarial tests; IPM module; Docker Compose setup.
